# البريد: تأكيد الحساب واستعادة كلمة المرور

كل شيء في التطبيق جاهز. الناقص **بيانات SMTP فقط** — وهي بيانات اعتماد لا يملكها
إلا صاحب المشروع.

## ليش SMTP ضروري وما ينفع بدونه

Supabase يرسل بخدمته الداخلية بحد **2–3 رسائل في الساعة للمشروع كله**، وهي
"للاختبار فقط" ورسائلها تروح للـ spam غالبًا. ومع ذلك:

> **Supabase يمنع تعديل قوالب البريد قبل ضبط SMTP مخصص.**
> «Set up custom SMTP to edit templates» — فحتى القوالب العربية في
> `docs/email-templates/` ما ينفع تُلصق قبل هذي الخطوة.

ولهذا **تأكيد البريد معطّل حاليًا**: لو فُعّل بدون SMTP، كل تسجيل جديد بينتظر
رسالة ما راح توصل.

## الخطوات — بالترتيب

### 1. جهّز مزوّد SMTP

أي مزوّد يشتغل. الأسهل للنطاق الجديد:

| المزوّد | المجاني | ملاحظة |
|---|---|---|
| Resend | 3,000 رسالة/شهر | الأبسط، يحتاج توثيق نطاق |
| Brevo | 300 رسالة/يوم | يقبل بريدًا بلا نطاق مملوك |
| SendGrid | 100 رسالة/يوم | |
| Amazon SES | رخيص جدًا | يحتاج خروج من الـ sandbox |

المطلوب منه خمس قيم: **host** و **port** و **username** و **password** و
**بريد المُرسِل**.

### 2. اضبطه في Supabase

`Authentication → Emails → SMTP Settings` → فعّل **Enable custom SMTP** واملأ:

```
Sender email    noreply@<نطاقك>
Sender name     دلال
Host            smtp.<المزوّد>.com
Port            587
Username        <من المزوّد>
Password        <من المزوّد>
```

### 3. الصق القوالب العربية

بعد حفظ SMTP تنفتح القوالب. من `docs/email-templates/`:

- `confirm-signup.html` → قالب **Confirm sign up** — الموضوع: `أكّد بريدك في دلال`
- `reset-password.html` → قالب **Reset password** — الموضوع: `استعادة كلمة المرور — دلال`

### 4. فعّل تأكيد البريد

`Authentication → Sign In / Providers → User Signups` → شغّل **Confirm email**.

من هنا: التسجيل يرسل رسالة تأكيد، والتطبيق يعرض «أرسلنا رابط تأكيد إلى بريدك»
بدل ما يدخل المستخدم مباشرة — وهذا المسار مكتوب أصلًا في `app/(auth)/actions.ts`.

## اللي انضبط مسبقًا

- **Site URL**: `https://dallal-v2.vercel.app`
- **Redirect URLs**: الإنتاج، ونطاق Vercel الطويل، و `localhost:3000` — كلها
  بنمط `/**`. أي رابط بريد يوجّه لغيرها يرفضه Supabase.
- **`/auth/callback`**: يستقبل الشكلين اللي يرسلهما Supabase (`?code=` و
  `?token_hash=&type=`)، ينشئ الجلسة على الخادم، ثم يحوّل. روابط الاستعادة
  تُحوّل إلى `/update-password` تلقائيًا.
- **`/reset-password`** و **`/update-password`**: صفحتان جاهزتان، والرابط
  «نسيتها؟» موجود في صفحة الدخول.

## قرار أمني مقصود

صفحة طلب الاستعادة تعطي **نفس الجواب** سواء كان البريد مسجّلًا أو لا. رسالة
«ما فيه حساب بهذا البريد» تعني أن أي شخص يقدر يكتشف من هو مسجّل عندنا، عنوانًا
بعد عنوان.
